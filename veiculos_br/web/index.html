🔔 Lembretes de leilão

Marque o sino num veículo favorito e escolha a antecedência. O aviso chega por e-mail e pela notificação do Windows quando o leilão estiver perto.

E-mail

O envio usa uma conta sua como remetente, com uma senha de app: uma senha especial gerada pelo provedor, que não é a senha normal. O Gmail é o mais simples:

  1. Ative a verificação em duas etapas da conta Google (myaccount.google.com → Segurança).
  2. Acesse myaccount.google.com/apppasswords, crie uma senha com o nome “Leilões” e copie os 16 caracteres.

Os lembretes são conferidos a cada 5 min enquanto o site estiver aberto. Para receber mesmo com o site fechado (PC ligado), rode uma vez: python -m veiculos_br lembretes --agendar. O horário vem da última coleta: rode python -m veiculos_br coletar com frequência para pegar remarcações.
